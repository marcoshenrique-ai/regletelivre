# Código de conduta

Queremos uma comunidade acolhedora para pessoas cegas, com baixa visão, educadores, familiares, voluntários e
desenvolvedores, com qualquer nível de experiência.

**Esperamos:** respeito; linguagem clara; paciência com quem está aprendendo; reconhecer que pessoas com deficiência
são especialistas na própria experiência; pedir consentimento antes de publicar relatos, imagens ou vozes de terceiros;
tornar acessível o que você publica (descreva imagens, evite informação só visual).

**Não toleramos:** assédio, discriminação, capacitismo, comentários depreciativos, exposição de dados pessoais ou de
saúde sem autorização.

Problemas podem ser relatados em privado a quem mantém o projeto. Quem mantém o projeto pode remover conteúdos e
afastar participantes que desrespeitem este código.

Inspirado no [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).
